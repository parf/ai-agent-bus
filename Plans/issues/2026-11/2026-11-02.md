Bug reports from live use, not a range review. Closed issues and their evidence are archived under [done](../done/).

## Access

- ⏳ J84 A correlated reply to an accepted ask is checked against the asker's Allow
  - → [Q323](../../R1.1/QUESTIONS.md#access-context)
  - Owner: `#ab-dir` decides; the change is ⚠️ A (authority) and a post-1.0 owner choice (raised 2026-11-02 by `#ab-lead2`, found by `#ab-w2c` in T-29 P1).
  - Repro: [`Send`](../../../src/internal/core/bus.go) checks the sender's access to the destination before anything else, and a reply is an ordinary `send` to the asker's route ([reply routing](../../../docs/04-messaging.md#reply-routing): the daemon keeps no reply state). A private agent whose `allow` lacks `#bus` can ask `#bus`, whose `allow` is `*`, and the question is accepted; `#bus`'s answer to it is a send from `#bus` to that agent, which that agent's `allow` does not admit, so the answer is refused. Focused repro: `TestDaemonPrivateAgentWriteStoresWithoutWideningReplyACL` in `src/internal/api/daemon_events_test.go` (T-29 P1, `#ab-w2c`; it pins that a private agent write stores without widening the reply ACL).
  - Affected: every private agent whose `allow` lacks `#bus`, for every `#bus` verb that answers (`status`, `version`, `ls`, `help`, and the agent-event verbs when a write waits). Existing behaviour, not new with agent events; it is the same for any responder an asker's `allow` does not name.
  - Existing coverage: [ACL](../../../docs/02-access.md#acl) says what governs access to a record and says nothing of an answer; [reply routing](../../../docs/04-messaging.md#reply-routing) says an answer is an ordinary `send`; the one answer-follows-reach rule is for a User and an Agent ([constitution § Channels](../../../docs/constitution.md#-channels): if the User may reach the Agent, the Agent may answer it). No decision names agent-to-agent answers ([decisions](../../../docs/decisions.md#settled) has none).
  - Choices (the owner picks; none is recommended here):
    - ( ) Keep as is and document it: an agent that asks `#bus` lists `#bus` in its `allow`, and the docs say so.
    - ( ) Let a reply to an accepted ask pass the asker's `allow`: the answer is admitted when it carries the route and tag of a request the asker was admitted to send, which needs the daemon to know the ask (today it keeps no reply state).
    - ( ) Something else: for example, admit only the daemon's own agent `#bus` to answer any agent that may ask it, leaving agent-to-agent answers as they are.
