## Runner

- ⚪ R1 `src/cmd/agent-bus-runner/status_line.go:36` an installed agent that is not configured yet makes the whole runner report "degraded"
  - Evidence: `#db` installed on 2026-10-28 with no database configured and `DB_USER` required in `env.dist`: state `refused: needs DB_USER`, runner "degraded: 3/4 running"
  - Impact: noise at install time; an operator reads "degraded" as a fault and a real failure hides behind it. The same holds for any package with a required key
  > 💡👾 Report a refusal caused only by a missing required key as `unconfigured`, counted apart from degraded; the db package no longer declares `DB_USER` required, so it is not affected.
