  - **B.18 plan for read-only review (2026-10-28; before code):**
    - **Shape and calls:** `src/agents/fetch/`, Python stdlib only, stateless runner-served `0..3` pool, sandbox on with network declared; no daemon/web change, credentials, persistent state, browser or JavaScript.     - **URL and address boundary:** URL <=4096 UTF-8 bytes; only HTTP/HTTPS, ASCII host (explicit IDNA conversion for ordinary domain labels), validated port 1..65535, no userinfo, fragment, controls, whitespace, backslash or ambiguous authority/zone id. Resolve A/AAAA once per hop with a bounded answer count (16); reject the entire hop if ANY answer is loopback/private/link-local/unspecified/multicast/reserved/non-global, including IPv4-mapped and known IPv6 translation/transition forms. Literal IPs use the same policy. No `.local`, localhost alias or numeric alternate spelling bypass: the resolved numeric address is what is checked. Keep the checked numeric result and connect a socket directly to its family/address; never ask the HTTP client to resolve the hostname again. Preserve original Host and HTTPS SNI/hostname verification against the original host, using the default verifying TLS context. No DNS-rebinding window from validate-then-resolve; one chosen checked address, no automatic connection retries/fallback. Tests inject a resolver and a connector ONLY as internal function arguments, never through env/Configuration/call fields; fake connector connects to a disposable loopback server while asserting the requested pinned public address.
    - **Redirects:** at most five hops, only 301/302/303/307/308 with one bounded Location. Close the old connection, resolve a relative Location with urljoin, then repeat full URL, ALL-answer and pinned-connection checks on EVERY hop, including same-host redirects and scheme/port changes. No implicit auth/cookies/referer carried. A private redirect or public-to-private DNS change is refused before any socket to that address. No subresource, image, stylesheet or link is fetched; links in output remain inert text/Markdown.
    - **Bounds and replies:** reuse `shared/provider_http.py`'s main-thread envelope deadline (60 s maximum, earlier caller deadline wins) for DNS, connect, headers, trickle/body and rendering, plus bounded socket waits from remaining time. Reply headers bounded before accumulation (16 KiB total, 64 lines); identity encoding only, no decompression bombs; response body <=1 MiB regardless of Content-Length/chunked framing, rendered output <=512 KiB; refuse a declared oversize early and still count actual bytes. No retries. Successful HTML/XHTML, text/plain and text/markdown become text or Markdown; reject unsupported/binary types and invalid declared decoding, with a small explicit charset allowlist. Non-2xx answers give bounded status/error without reflecting a URL, Location, body or raw exception. Logs contain status and byte counts only; never URLs/query values, fetched text or inherited credentials. Output is untrusted external content, not instructions; describe that boundary in help/guide.
    - **Extraction:** one bounded `html.parser.HTMLParser` pass; drop script/style/head/noscript/template and hidden content, preserve paragraph/heading/list spacing, decode entities, normalize whitespace without joining words. Markdown conversion escapes text and unsafe link syntax, includes only sanitized HTTP(S) links, and never emits raw HTML/javascript/data links. Bound nesting, tag count and output while building; malformed HTML cannot create unbounded stacks or quadratic concatenation. Plain/Markdown text is not executed or fetched again.
