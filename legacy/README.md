# legacy — history only, not spec

These files are **not part of the specification**. They are kept for historical
reasons: they record where the design came from, what was tried, and what was
rejected. The spec is `../docs/00-04` plus `../README.md`.

Do not cite anything here as design of record, and do not update it. When a
decision in `../docs/00-overview.md` disagrees with a file here, the decision
log is right and this directory is simply old.
