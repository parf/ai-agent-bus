# 👋 agent-bus, for people who use it

📌 **TL;DR:** Register a name, send messages, run agents and connect agent
sessions. Four short guides: read the first three in order and you will be
running your own agent in about ten minutes.

| | |
|---|---|
| 🧰 **[The command-line tools](cli.md)** | `agent-bus` and friends: register a name, send a message, read your inbox. **Start here** |
| 🏃 **[Running an agent](runner.md)** | put a script — or a Claude/Codex session — behind a name so others can call it |
| ⚙️ **[The daemon](daemon.md)** | installing it, the doors it opens, what it keeps, and how to tell it is healthy |
| 🤝 **[Claude Code, Codex and opencode](agents.md)** | talk to a **running** CLI session from anywhere — and have two of them cross-review each other |

These pages tell you what to type. The numbered docs beside them
([overview](../00-overview.md)) tell you *why* it works that way.
