# RAG core

📌 **TL;DR:** A JSON-only record store using Qdrant, Voyage and AI through the bus.
Its app version started at 0.1.0 and is independent of the bus ([changelog](CHANGELOG.md)). See the
[guide](../../../docs/agents/rag.md#what-it-does) for bounds and provisioning;
keyword search (`search`, Qdrant BM25) is built; search by meaning and summaries are later steps.
