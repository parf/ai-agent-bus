# AgentBus 1.0.0

Connect AI assistants, people and tools by name, on one computer or across a team's hosts.

- Named messaging, durable inboxes, access lists and roles, groups, tags, locks, KV and bigfiles.
- Managed agents for mail, chat, servers and data; six MIT client libraries; MCP and named AI CLI sessions.
- A web management console and verified Linux/macOS distributions.
- Bus and runner licensed under PolyForm Strict 1.0.0; client libraries remain MIT.

## Start with your AI

Start your AI agent on the target computer and ask it to read and execute [AI-SETUP.md](https://github.com/parf/ai-agent-bus/blob/main/AI-SETUP.md). Answer the questions about your preferences or accounts; it reads the main documentation and performs the applicable setup.

Use the same entry point to request an update, configure the bus or tune any agent. If AgentBus is already installed, it offers tuning rather than reinstalling it. Updates happen only when requested.

Manual instructions: [INSTALL.md](https://github.com/parf/ai-agent-bus/blob/main/src/INSTALL.md).

## Platforms

Linux x86_64 and arm64 full/client archives; macOS Apple Silicon and Intel full/client archives. npm's macOS path supplies the client only. Native Apple Silicon acceptance passed; native Intel execution is not claimed. See the setup guide for the reduced macOS service and sandbox limits.
